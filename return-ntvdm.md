# return-ntvdm.md — retired 2026-08-26

This file was the project's single rolling handoff document for 29 sessions. It grew to
4,000 lines of reverse-chronological narrative: excellent as a scratchpad, impossible to
hand to anyone, and — because there was also a `docs/STATE.md` that had gone three weeks
and four milestones stale — one of *two* documents each claiming to be canonical.

It has been split, **verbatim and without edits**, into a per-session archive.

## Where things went

| You want | Go to |
|---|---|
| **Where the project is now, and what to do next** | [`docs/STATE.md`](docs/STATE.md) — the single canonical resume point |
| What happened in a given session | [`docs/log/sessions/`](docs/log/sessions/) |
| The accumulated rig operations, instruments and traps | [`docs/log/sessions/standing-reference.md`](docs/log/sessions/standing-reference.md) |
| How something works, and why it was done that way | the [wiki](https://github.com/MrMatthewLayton/ntvdmex/wiki) |
| What is left to do | the [issue tracker](https://github.com/MrMatthewLayton/ntvdmex/issues) |

Nothing was lost in the split — it was verified line by line, refutations and all. The
conclusions that later sessions overturned are still in there on purpose: on this project
the refutations have consistently been worth more than the conclusions.
