# Work Log

Chronological journal of work, learnings, decisions, and surprises. One file per day
(`YYYY-MM-DD.md`). Newest day is the most recent file.

**At the end of each session:** append today's entry here *and* update
[../STATE.md](../STATE.md). The pair is the resume contract.

Suggested entry shape:

```markdown
# YYYY-MM-DD

## Done
- …

## Learned
- … (tag [FACT]/[BELIEF]/[VERIFY])

## Decided
- … (link the ADR)

## Surprises / dead-ends
- …

## Next
- …
```
