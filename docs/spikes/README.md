# Spikes

Time-boxed experiments that answer a specific risk question with the least possible code.
A spike is **throwaway** — its output is *knowledge* (recorded here), not production code.

Each spike doc: **Question → Hypothesis → Method → Success criteria → Result → Decision impact.**
