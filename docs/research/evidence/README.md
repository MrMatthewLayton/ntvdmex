# Evidence

Screen captures kept as the **proof behind a claim made elsewhere in the docs**. They
live here rather than in `build/` because `build/` is generated and gitignored: these
were tracked by accident before that rule existed, and a claim whose evidence sits in a
directory everyone is told to delete is a claim that quietly loses its backing.

Nothing here is regenerated by a build. If you re-run the tests you will get *new*
captures; these are the historical ones the write-ups actually refer to.

| Directory | What it shows | Backs the claim |
|---|---|---|
| `mode12-demos/` | Frames from the ten QuickBASIC demos (`demos/`) rendering in EGA/VGA planar mode 12h | "All 10 demos watched live: **zero pixel defects**" — the M3/mode-12h write-up. The demos themselves are in `demos/`, sources in `demos/src/`. |
| `doom/` | Doom frames: a mid-game frame, the mode-Y path working, and a page-4000 capture | The DPMI/graphics milestones — that Doom's own 32-bit code renders through our video path. |
| `mouse/` | `mouse_stock.png` vs `mousetst_live.png` | The **stock-ntvdm oracle** comparison: the same program under Microsoft's ntvdm and under ours, side by side. This is the pattern the project leans on constantly — see the oracle notes in the wiki. |

> ⚠️ Third-party reference screenshots (MobyGames captures of real Doom, used to eyeball
> our rendering by hand) are **deliberately not committed** — they are not ours to
> redistribute and this repository is public. They are gitignored as `doom-screenshots/`.
